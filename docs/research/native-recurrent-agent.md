# Native interface for a shared recurrent learner

`NativeRecurrentAgent` connects the original Julia matter simulation to an external shared-parameter trainer. Each physical resident has a private recurrent state in the trainer; identity masks reset it at birth/reuse and cut reverse gradients. The shared optimizer is external computational training, not autonomous biological learning, evolution or paid local parameter adaptation. Physical movement, uptake, growth, reserve metabolism and secretion still pay their original native costs. No physical reward or substrate is supplied by a training update.

The current25-dimensional input is species-resolved raw/soluble/catalyst A/B receptors (6), battery/capacity, A/B stores/capacity, mass/(division mass+mass), age/(20+age), interval funded secretion/mass (6), and the previous11 native regulated actions plus two material request commands (13). Species values are support-weighted concentration/(1+concentration), sampled at the **start of the last native physics step**. Body values are from that step's completion. This is an explicitly delayed material observation, not a simultaneous snapshot. Time, source phase and environment identity are absent from network inputs. One declared .02 native initialization step supplies real initial receptors before training decisions begin.

First-stage active channels are investment, allocation and reserve fraction, with physical ranges[0,.3],[0,1],[.02,.25]. Their raw Gaussian actions pass through a sigmoid and affine scaling. Initial means select investment.15, allocation.5 and reserve.035; the latter avoids the known precursor-priority trap of an unexamined zero-bias reserve.135. Failed construction remains part of experience. Other native actions remain native-controller outputs rather than frozen zeros. The generic decoder supports all13 native/material channels; the new default-no-op controller override hook runs after native neural outputs and before native regulation, so future metabolic action control does not duplicate or bypass enzyme/uptake physiology.

`make_env` returns device arrays x,incoming,valid,ids. `act!` saves current identities and values, resets interval transfers, and installs held actions. `advance!` runs one .2 interval, returns reward/outgoing/target/predvalid and prepares the next x/incoming. Repeated observation at the same completed step does not turn a newborn reset mask into a continuation. The incoming recurrent-state mask and outgoing reward/bootstrap mask are distinct.

The task reward is the change in replacement-equivalent developmental value, `E+η(pA A+pB B)+[η(pA+pB)/2+growth_work]m`. It makes ideal growth neutral and is not a fitness theorem. Actual child value at native partition is restored to a pending parent's accounting once per child identity; later descendant production is not credited. A dead or reused initial identity has endpoint zero and no bootstrap; a newborn has no fictitious predecessor action/reward. Prediction targets are the next12 physical observations only when the resident identity survives. A recurrent head without the current sampled action as input is an **on-policy next-observation predictor**, not an action-conditioned world model or counterfactual simulator.

The runtime is dimension-generic, with shared trainable input/recurrent/head matrices and persistent private hidden states. Truncating a training window must detach gradients while carrying hidden state; it must not reset every resident at each block. Width, unroll length, amount/distribution of experience, and held-out source histories remain explicit experimental axes. The authored finite-program experiment is a baseline and affordance assay, not the destination architecture.

## Current verification and continuation boundary

The final adapter revision passes26 focused CPU checks (`outputs/recurrent-agent-tests-v3.log`): every native cell-state array matches direct native stepping when no commands are installed; all13 decoder mappings reach the intended shared physiology boundary; the funded initial operating point produces actual secretion; incoming masks are idempotent; replacement IDs cannot inherit old material-command or funded-history features; partition gifts are credited once; reused identities receive terminal reward without bootstrap; raw action dtype/domain/clock guards and physical material/potential closure hold. A standalone actual .2 decision with24 residents funded .1385904 construction at the initialized reserve.035.

The generic recurrent runtime has separate CPU gradient and AMD execution evidence owned by its runtime module. The final adapter identity fix is **not yet covered by a completed integrated CPU/AMD physics-plus-training comparison**. The first remote pipeline stage was deliberately interrupted before evidence collection when that identity fix arrived. The user requested wind-down before a replacement stage; no replacement run or exporter was started. Next work is a fresh pinned integrated native gate, followed by useful shared training across the declared varied environments and held-out evaluation. The earlier finite-program native gate does not substitute for this missing integrated check.
