# Continuing temporal allocation in living matter

This separate study connects the physical ramp lesson to moving, dividing residents. It does not install the episodically learned ramp coefficients or assume that the same allocation sign is useful in a garden. The original living scene and its23-feature policy remain unchanged.

`native_temporal_living.jl` shares the native step schedule, actuator request helper, decision-aligned maturity/payment transaction, and living birth-transfer accounting. Its new policy reads a three-coordinate equal-norm bank: bias, `x=tanh(raw_balance/.2)`, and `sign_plus(fast−slow)*sqrt(1−x²)`. The matched instantaneous bank replaces only the history sign with the sign of current raw balance (zero maps to+1). This also supplies an odd current-input nonlinearity, so the history arm cannot win solely by adding that static basis function. Both have squared norm2 and both continuously update the same local filters. Neither actor sees a source phase, clock, source mask or external context label. This is a controlled representation change, not a comparison against every possible recurrent controller.

Only allocation is explored and learned. Investment and reserve are fixed at declared operating values (derived below); the new recipe uses allocation exponent1, so composition changes preserve total requested construction. Native precursor affordability and work still determine funded construction. The three stored action axes retain the shared cohort and birth ABI, but investment/reserve scores are zero and their coefficients remain zero.

Filters observe every.2 physical time independently of the action cadence. The first pilot decided every.2; the second phenotype holds an actual sampled drive for1 time while filters continue observing. Newborns initialize both timescales from their first actual native reading, creating no invented trend. The next observation uses the actual elapsed interval since that reading, including off-cadence births. Learned readout inheritance, when enabled, still pays the child's actual battery; filter history is reset rather than copied. Old occupant identity mismatch clears private credit and predictor state. Overlapping cohorts retain the pre-action feature, Gaussian score, usable inventory and predictor baseline; maturity uses the existing paid updater. Known native partition gifts adjust pending parent returns exactly as in the original living law.

The predictor uses the same information in both actor arms: a scaled bias/current/history bank plus bounded energy fraction, store balance, raw total, catalyst total and previous return. Scale is explicit and will be assessed against measured attainable returns and saturation. It is not evidence that the previous living predictor was range-limited. All coefficient changes pay the existing price; scaling predictor features changes cost per unit prediction change and is part of this new law.

Before training, `authority` takes actual living checkpoints at2,4 and6, covering the original four-time source-mask exchange. Each branch starts from an independent copy of the entire physical and private state. It commands allocation logits−1,0,+1 for.4, then resumes the same deterministic policy. Captures at lags1,2,4 report requested/funded construction, actual local readings and individual usable-inventory returns adjusted only for recorded births by that same parent. No material is erased and source clocks, masks, remaining budgets and existing deposits continue. This map determines whether history predicts useful local allocation authority before a learning result is interpreted.

## Designing an operating regime with real authority

The original-stock pilot with investment.4 completed75 focused checks but showed only small pulse authority: average absolute ±1 allocation return differences were roughly2.5e−5–3.7e−4 across the sampled lags, against ordinary returns around1e−2. History did not provide a stable allocation sign. The higher investment also changed total demand relative to the original living controller. The intended new law therefore fixes investment at `sigmoid(-.8)/2≈.155013`: with exponent1 this matches the original exponent2 policy's centered total request.

The separate washout design ties physical timescales together. Raw initial concentration is.08; source rates are.8 per channel over volume8 (mean density.1), uniform sink rates.96 per channel (density.12), mask persistence8, and catalyst decay.2 (lifetime5). The physical exchange diffusion time remains `.18²/(6*.006)=.9`. At the strongest patch, high/low source densities are approximately.195/.005; after sink subtraction, new stock grows at.075 and old stock clears at.115. This puts a composition crossing a few time units after a switch, with several time units of predictable supply remaining. Sources and sinks have finite declared budgets25.6 and30.72 per channel, respectively. They export/import actual material and potential through native ledgers.

The first washout map had **exactly zero** late pulse authority: secretion stopped at cumulative.44378 and no births occurred. By8, raw supply was12.8 while sinks had exported12.47. Adding a balanced precursor source of.1 per channel (finite3.2 budget each) alone did not restore actuation. Both records are preserved. This precursor source provides no directional cue and is an explicit maintenance boundary, not free internal food. With native efficiency.65 and potential4, the founders' basal precursor-equivalent demand is about.118/time before neural and motor costs; total precursor supply.2/time leaves a possible margin only if transport and budget priorities permit uptake and construction.

The next correction addresses the actual priority: native energy capacity is3, so reserve fraction.2 asks for.6 energy per biomass. The pilot retained usable inventory near1.02–1.04 per resident while construction remained unfunded. The new reserve fraction.02 asks for.06 per biomass, about7.5 basal-time units before neural/motor costs, comparable to the8-time supply phase. It releases physical battery headroom and precursor flow for construction without adding inventory. This is a declared fixed operating phenotype for the allocation experiment; it does not establish that low reserves are generally better or that the original joint reserve policy cannot learn.

The filter machinery is identical in history and instantaneous arms. It remains part of the study controller's information state; existing neural physiology is unchanged, and learned readout/predictor coefficient changes use the original explicit battery/work price. No extra chemical inventory is assigned to filter state. A future chemical implementation would need its own turnover law rather than treating this computational representation as a quantified molecular cost.


## First continuous pilot and the next construction phenotype

The first24-time uninterrupted comparison produced48 residents and24 births in each arm. Frozen24→28 probes preserved each arm's physical state, remaining finite budgets and source phase. History readout improved mean transfer-adjusted return by4.086e−6 relative to erasing its learned coefficients; swapping its history sign yielded−6.177e−6 relative to erasure. The instantaneous control's difference was−2.411e−6. No-credit learned/erased/swapped probes were exactly equal. These small changes establish working controlled machinery, not substantial learned ecological capability. The actor made3796 paid updates, about15.5% of coordinate proposals clipped, and predictor coefficients remained below.016: predictor saturation was not the observed obstruction.

The funded authority map explained a more useful next design. From8→12, funded construction averaged about.022 world units/time while biomass grew about.163/time; roughly2.6% of requested construction was funded. Moreover each sampled action lasted only.2 within a4-time return horizon. The separate `living-temporal-construction-16.toml` phenotype slows growth request rate from.8 to.1 and holds allocation decisions for1 time. Filters still sample every.2, source persistence remains8, catalyst lifetime5, exchange diffusion time about.9 and return horizon4. Thus four overlapping cohorts replace twenty, while one action can fund a meaningful deposition interval. This changes the operating phenotype openly; initial stock, external budgets, maintenance supply and reserve.02 remain the same. It does not claim slow growth is universally preferable.

The shared construction sidecar now exposes the already-existing `decision_time` option with unchanged default.2. Focused checks compare implicit/explicit defaults, held drive between observations, off-cadence newborn initialization, partial-state continuation, actual maturity and paid learning. Original pilot sources and reports remain immutable. All frozen comparisons report initial resident count and survival; a survivor-conditional return is never presented as whole-cohort benefit when deaths occur.

The separate native gate advances the new cadence for9 uninterrupted time units on CPU and AMD. It deliberately starts near division with a nonzero allocation readout to test paid child copying; this is coverage, not a learned-inheritance result. All integer temporal/private/queue arrays matched exactly, maximum compared floating discrepancy was2.146e−6,24 actual births included funded nonzero copies, paid actor updates occurred, and maximum material/potential residual was2.19e−14. This does not validate GPU deep-copy forks: frozen experiment branches currently use independent CPU copies. GPU forks require explicit physical/private/temporal restoration and a separate equal-future gate.
