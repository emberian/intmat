# Sharing conditional action evidence while retaining specialization

The developmental-value comparison corrects growth accounting but leaves learned effects small. At time12 the measured graph has26 residents,15 bonds and14 components; its largest component contains six cells. A simple population-average policy is unavailable to this local graph. More importantly, selected cells have conflicting allocation effects. ID5 is bonded only to a newborn with no learned evidence. Averaging their readouts would dilute the parent's estimate, not add an independent observation.

The proposed component shares evidence about context-dependent response while retaining each source's private action intercept. It is not yet a living-policy law. `studies/local_action_evidence.jl` is a small reference implementation; its12 tests cover exact agreement with block ridge regression, opposite local preferences, and zero influence from an evidence-free newborn.

For source i, a matured decision provides pre-action context x=(current balance, temporal contrast), sampled allocation innovation ε, and developmental return less its frozen pre-action baseline y. Define v=ε(1,x). Keep only the source's original sufficient statistics A_i=Σvvᵀ and b_i=Σvy. Fit the explicitly approximate response model y≈ε(α_i+β·x), with private action intercept α_i and common contextual slope β. This is ridge response estimation, not an unbiased policy-gradient estimator. Nonlinear action responses, overlapping returns, changing peers and omitted local variables can all violate the approximation.

Partition A_i into intercept scalar a, cross vector c, and context block B, and b_i into d and e. After adding a fixed intercept ridge ρa, eliminate α_i locally:

    S_i = B_i − c_i c_iᵀ / (a_i + ρa)
    t_i = e_i − c_i d_i / (a_i + ρa)
    β = (ρβ I + Σ S_i)⁻¹ Σ t_i
    α_recipient = (d_recipient − c_recipientᵀ β) / (a_recipient + ρa)

Thus neighbors can inform a context-response slope without imposing their preferred action at the recipient. If a resident never experiences varying contexts, its context effect is largely indistinguishable from its intercept. The reduced information matrix exposes that lack of identification; a constant-context neighbor is not automatically useful merely because it has many samples. A fixed ridge is an explicit modeling prior, not evidence.

A continuing implementation should gather only original statistics from current, stable-ID-validated bond neighbors. It must never retransmit a pooled aggregate as original evidence. Reading a fresh one-hop snapshot avoids recursive evidence multiplication; replacing a neighbor's snapshot is different from accumulating it again. Births initialize original evidence to zero, regardless of any separately paid inherited policy. Stored decisions retain the actual pre-action context and identity. Death and slot reuse invalidate identity-associated caches.

The native representation is six symmetric Gram entries plus three RHS entries, a count and an ID per resident. Two-phase gathering uses immutable original statistics, then writes recipient proposals; it must not depend on launch order. The two-dimensional solve has a direct scalar form suitable for a fused Julia kernel. The CPU reference currently uses LinearAlgebra for clarity and is not a GPU implementation or performance claim.

Before a paid continuing law, the bounded empirical gate is to record actual matured tuples in the funded developmental fixture, inspect the reduced information matrices within real bond components, and test response predictions on withheld decisions or matched ± single-resident interventions. Parameter consensus, own-evidence response fitting and neighbor-evidence fitting are distinct controls. Success requires useful conditional predictions or paid policy improvement; agreement among cells alone is not success.

Communication and readout construction will be separate affordable transactions in the continuing law. A message must pay an explicit declared cost from actual battery, with the same work ledger used by learning, before its information becomes available. Coefficient changes also pay their actual mark-turnover cost. A failed payment cannot expose the message or install the proposal. Message cost is a new constitutive parameter, not something inferred from physical carbon stoichiometry; it must be reported alongside benefits. No new chemistry inventory, substrate transfer or colony reward is implied by a bond message. The current helper performs inference only and claims no paid-communication implementation.

## Actual-trace identification gate

The read-only recorder replayed the immutable developmental history arm exactly: final complete observation, paid work, actor-update count and clipping count match the original. It recovered543 matured tuples. The fixed split uses216 eligible tuples with maturity through16, and120 held-out decisions at20–24 belonging to sources with training evidence. The larger held-out candidate count135 includes residents without fitted original evidence; these are explicitly excluded, not assigned fictitious trained estimates. Neighbor membership is the actual time16 graph and remains fixed for this predictive diagnostic.

At the predeclared ridge.1, own-evidence response MSE is.0007483, bond-conditioned response MSE.0006981, and zero-response MSE.0004284. Pooling increases the median weakest context-information direction from.001664 to.008149, but the resulting prediction still performs worse than zero. Fixed sensitivity values.01 and1 also fail to beat zero; these are reported together, not selected as successful fits. The return residual includes substantial unrelated fluctuations, so this is not proof that local causal action effects vanish. It does reject deploying this estimator on the present amount of experience merely because pooled parameters look more consistent.

The concrete next architecture should obtain a stronger signal before charging for communication: learn a local predictive material model from frequent material observations, then use explicit chemistry and the learned forecast to choose a construction allocation. That changes the learning architecture rather than adding more neighbors to a noisy whole-cell-return regression. A future prediction-driven controller must still test actual paid downstream return, transport/access limitations and counterfactual action effects; accurate forecasts alone are not useful construction. The existing response component remains available for an environment with enough identifiable conditional action evidence.
