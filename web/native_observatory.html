What this window shows

The observer reads only frame entries in the run manifest and verifies their SHA256 before detached CPU export. It never reads a partial checkpoint, resumes a run, reseeds cells, or simulates motion. Playback jumps between recorded physical times. Every exported observation is retained.

Native voxel concentrations and explicit block means are labelled separately. Ray marching and spatial interpolation are display transfer functions. The periodic domain is shown as a finite view boundary, not an enclosing gel wall. Bond lines show shortest periodic displacement; hidden seam partners remain labelled in the inspector.

Source frames currently report realized secretion from the last physical step only. This is not accumulated secretion over the capture interval.
